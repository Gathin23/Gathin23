## CleanYourTV

On 17 October 2026 I gave Claude Code my parents' TV model number because it was showing a sponsored ad before you could even get to Netflix. It found the TV on Wi-Fi, removed 25 Xiaomi packages and wrote a new launcher. I [posted it on X](https://x.com/gathint/status/2111379569030939102), and it turned into **[CleanYourTV](https://github.com/Gathin23/cleanyourtv)**: debloat any Android or Google TV over Wi-Fi and get an Apple TV-style home. No root, no cable, nothing uninstalled, and a one-line restore.
